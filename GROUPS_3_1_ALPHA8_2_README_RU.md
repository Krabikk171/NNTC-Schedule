# NNTC Schedule 3.1.0-alpha.8.2 — обновление технического ядра

## База

Патч рассчитан на **NNTC Schedule 3.1.0-alpha.8.1 (merged source)**, а не на alpha.7 и не на случайную копию Android Studio. Изменяются только файлы парсера общего каталога, тестовые ресурсы, changelog и номер сборки. Ни один файл Compose/настроек оформления/экрана «Маршрут» не заменяется. Если в другом чате уже установлена экспериментальная «Лента», она останется на месте при применении core-only патча к совместимой базе.

## Новое PDF

Документ «Расписание занятий учебный корпус №2 (4).pdf» содержит дни 19, 20 и 21 ноября 2026 года на 3 страницах. Важная особенность — один день может продолжаться на следующей странице, а на одной странице может быть более одного дня.

Результаты локальной координатной проверки (глифы извлечены из настоящего PDF; тесты JVM):
- 17–18 ноября: 32 группы / 194 пары / 31 без структурных замечаний / 1 с замечаниями.
- 18–19 ноября: 32 / 187 / 32 / 0.
- 19–21 ноября: 32 / 248 / 32 / 0.

«Без структурных замечаний» не гарантирует точного смыслового совпадения с оригиналом: это только автоматическая проверка, сверка сложных строк по PDF по-прежнему необходима.

## Исправления

1. Пустая строка группы в конкретный день не считается ошибкой, если в ячейках действительно отсутствуют предметы. Если текст предмета есть, но пара не извлечена, предупреждение остаётся.
2. Окончание длинного предмета у соседней группы не должно попадать в целевой предмет. Для этого использован ближайший к строке непрерывный блок с завершённым ФИО преподавателя; варианты с параллельными подгруппами сохраняются без такого обрезания.
3. ФИО с переносом фамилии и инициалов на разные строки обрабатывается без приклеивания следующего предмета.
4. Кабинет «105 а» распознаётся как «105а», а не «105» с буквой «а» внутри названия предмета.
5. В новый тестовый набор включена сверка 19 ноября между двумя публикациями: `4ТЭО-23-1` действительно меняется с 4–6-й на 3–4-ю пару; `2РПУ-25-1` остаётся неизменной.

## Изолированное применение

Сделайте резервную копию проекта. Из корня Android-проекта запустите:

```powershell
python tools/apply_patch.py --patch "C:\Downloads\NNTCSchedule_3.1.0-alpha.8.2_core_patch.zip" --project "C:\Android\Projects\NNTCSchedule"
```

Скрипт создания патчей также исключает Python `__pycache__` и `.pyc` из архивов. Скрипт применения проверяет SHA-256 старых файлов: при конфликте с дизайнерской веткой **не перезаписывает** другой код. Если у вас ещё нет `tools/apply_patch.py`, он включён в полный архив alpha.8.1 и выше.

Проверьте в Android Studio:

```powershell
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest
```

В этом окружении выполнялся отдельно Kotlin JVM-компилятор с локальным совместимым JUnit-харнессом: **40 проверок прошли**. Реальная сборка Android, Material 3, Room и миграции устройства здесь не подтверждались.

### Важно о дизайне

Ветка дизайнера после alpha.8.1 добавила экспериментальную **«Ленту»** и отдельное исправление в `ui/theme/VisualEffects.kt`. Этот технический ZIP **не содержит** этих новых дизайнерских изменений; он их и не перезаписывает. Полный `alpha.8.2_source.zip` — техническая база с включённым «Маршрутом» из alpha.8.1, но без ещё не слитого в эту базу свежего патча «Лента». Не копируйте полный проект поверх более нового локального дизайна без сравнения.
