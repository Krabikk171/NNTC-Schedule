# NNTC Schedule 3.0.0-alpha.5 — три стиля интерфейса

## Что добавлено

В настройках теперь есть независимый раздел **«Стиль интерфейса»**:

- **Minimal** — прежний минимализм, включён по умолчанию.
- **Aurora** — мягкие сиренево-голубые переливы, полупрозрачные карточки и градиентная кнопка.
- **Neon** — более контрастные тёмно-фиолетовые/розовые цвета, светящиеся акценты и градиентная кнопка.

Настройка **«Оформление: Системная / Светлая / Тёмная»** сохранена и действует отдельно. Каждый стиль имеет светлую и тёмную палитры. Переключение применяется сразу и сохраняется после перезапуска.

Декоративные эффекты рисуются штатными средствами Jetpack Compose (Canvas / Brush). Файлов картинок и дополнительных зависимостей не требуется. Это реализация стилей, основанная на концептах; точное фотореалистичное свечение и 3D-детали генераций не воспроизводятся.

## Что НЕ менялось

В сравнении с исходным архивом `3.0.0-alpha.4` побайтно сохранены:

- `ScheduleRepository.kt`, `ScheduleCsvCodec.kt`, `v3/ScheduleTableParser.kt`;
- `PdfDownloader.kt`, `ScheduleUpdateWorker.kt`, `ScheduleWorkScheduler.kt`;
- `ScheduleDao.kt`, `ScheduleDatabase.kt`, `NotificationHelper.kt`.

Пакет приложения **ru.krabikk.nntcschedule** не менялся: установка поверх предыдущей сборки сохраняет пользовательские данные, если приложение подписано совместимым ключом. Не удаляйте приложение/данные для переключения стиля.

## Как установить

### Самый простой способ — полный исходный проект

1. Сделайте копию своей рабочей `alpha.4`.
2. Распакуйте `NNTCSchedule_3.0.0-alpha.5_styles_source.zip` и откройте папку `NNTCSchedule` в Android Studio.
3. File → Sync Project with Gradle Files.
4. Build → Make Project, затем `:app:assembleDebug`.
5. Установите APK как обычно. В приложении: **Настройки → Стиль интерфейса**.

### Только изменённые файлы

Распакуйте `NNTCSchedule_3.0.0-alpha.5_styles_patch.zip` в корень существующего проекта, сохранив структуру папок и заменив совпадающие файлы. Обязательно переносите **новые** файлы `InterfaceStyle.kt` и `ui/theme/VisualEffects.kt` вместе со всеми изменёнными — иначе импорты будут красными.

## Compose Preview

Откройте `ScheduleHomeUi.kt`: шесть Preview показывают Minimal, Aurora и Neon в обеих режимах (светлый/тёмный). Preview использует тестовые данные и не загружает PDF.

## Проверка

- [ ] `:app:assembleDebug` завершается успешно.
- [ ] Настройки → Minimal / Aurora / Neon меняют оформление без перезапуска.
- [ ] Отдельно переключаются Системная / Светлая / Тёмная.
- [ ] После перезапуска выбранный стиль не сбрасывается.
- [ ] Длинные названия предметов не обрезаются.
- [ ] Нажатие «Проверить обновления» работает как в alpha.4.

## Ограничения проверки

В среде подготовки не удалось получить Gradle 9.6.0 (`UnknownHostException: services.gradle.org`), поэтому **полная Android-сборка здесь не подтверждена**. Отдельный файл `InterfaceStyle.kt` прошёл локальную компиляцию Kotlin. Полная сборка и визуальный тест нужны в Android Studio.

В следующем этапе можно добавить четвёртый декоративный стиль Lavender, не меняя интерфейс настроек принципиально.
