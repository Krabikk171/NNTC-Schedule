# NNTC Schedule 3.1.0-alpha.5 — Первый запуск и профиль

Ветка от `3.1.0-alpha.4`.

## Что добавлено

- При первой установке и при первом открытии после перехода на alpha.5 со старых версий показывается приветствие: «Студент» / «Преподаватель».
- «Преподаватель» пока не работает: предусмотрен честный информационный диалог, без вымышленного расписания.
- Для студента доступен поиск по группам (32 группы из PDF за 18–19 ноября как стартовый список + группы из актуальной базы Room). Наличие группы в списке **не означает**, что её расписание уже загружено.
- Выбор сохраняется в DataStore вместе с флагом завершения мастера, одним атомарным действием. До подтверждения прежний выбор остаётся без изменений.
- «Настройки → Профиль и расписание → Изменить роль или группу» повторно открывает мастер. Можно отменить выбор.
- Выбор группы на главном экране обозначен явно: «ВЫБРАННАЯ ГРУППА / Нажми, чтобы изменить группу».
- В «О приложении» указано: `Разработчик: Krabikk171` и `Вы можете найти меня в Telegram: Krabikk171`. Ссылка не добавлена без проверки точного Telegram-username.
- Номер версии: `3.1.0-alpha.5`, versionCode 25.

## Что не менялось

Парсер PDF, CSV, Room, загрузчик, Worker и уведомления не изменены. Режим преподавателя остаётся целью следующего большого обновления.

## Как проверить на эмуляторе

1. Сохраните резервную копию alpha.4 и установите alpha.5 поверх неё. При первом открытии появится мастер. Он не должен появиться при повторном запуске.
2. Выберите «Студент», найдите `2РПУ-25-1`, подтвердите. Прежние сохранённые занятия должны отображаться.
3. Откройте «Настройки → Профиль и расписание», выберите другую группу, перезапустите приложение, проверьте сохранение выбора. При отсутствии занятий выполните обновление PDF.
4. Откройте мастер ещё раз и нажмите «Отмена»: выбор не должен измениться.
5. Нажмите «Преподаватель»: появится сообщение, что режим находится в разработке.
6. Откройте «О приложении» и проверьте имя разработчика.
7. Переключите светлую/тёмную темы и стили Minimal, Aurora, Neon, Lavender, Ocean; проверьте читаемость мастера.

⚠️ Это исходный проект, не APK. Полную сборку `:app:assembleDebug` нужно проверить в Android Studio.
