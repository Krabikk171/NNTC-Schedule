# NNTC Schedule — 3.0.0

Приложение для чтения расписания ННТК из PDF, хранения занятий на устройстве и показа выбранной группы в удобном интерфейсе.

## Новое в 3.0.0

- PDF → структурированное расписание → CSV → Room.
- Поддержка нескольких дат на одной странице PDF и продолжения на следующей.
- Защита старого расписания при недоступном или ошибочном PDF.
- Пять стилей оформления: Minimal, Aurora, Neon, Lavender и Ocean; светлый/тёмный/системный режим.
- Лента дней и возможность её отключить.
- Плавные анимации, улучшенный контраст, адаптивные карточки.
- Раздельные статусы последней успешной проверки и последней неудачной попытки.
- Диагностика в меню разработчика с копируемым отчётом.

## Как открыть проект

1. Открыть вложенную папку `NNTCSchedule` в Android Studio (там находятся `settings.gradle.kts` и `gradlew.bat`).
2. Выполнить `File → Sync Project with Gradle Files`.
3. Запустить `:app:testDebugUnitTest` и `:app:assembleDebug`.
4. Установить полученный Debug APK либо использовать Run на телефоне. Для публикации нужен отдельно собранный и подписанный Release APK/AAB.
5. При обновлении поверх старой версии использовать тот же `applicationId` и совместимую подпись; не очищать данные приложения.

## Что осталось проверить перед распространением

Пользователь подтвердил работу основной версии на телефоне и успешное сохранение данных при ошибке сети. Полная Android-сборка этой **именно релизной исходной версии** в среде подготовки не проводилась из-за отсутствия Android SDK. Фоновые запуски WorkManager, получение уведомлений о реальном изменении и будущие форматы PDF требуют дополнительной проверки. См. `RELEASE_CHECKLIST_RU.md`.

*Секреты и ключи подписи не входят в исходный архив.*
