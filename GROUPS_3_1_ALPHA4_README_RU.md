# NNTC Schedule 3.1.0-alpha.4 — выбор группы

## Что сделано

- Каталог всех групп из PDF сохраняется в **отдельной** базе Room `nntc_group_catalog_v1.db`.
- Загруженный PDF разбирается рабочим парсером 3.0.0 для `2РПУ-25-1`, затем независимым диагностическим парсером для остальных групп.
- При ошибке диагностики прежняя контрольная группа и её база остаются прежними; неудачное обновление каталога не должно удалять старый каталог.
- На главном экране нажми на строку **«Группа»**, чтобы открыть выбор с поиском. Выбор сохраняется в DataStore.
- Для групп с замечаниями показано предупреждение, чтобы их расписание обязательно сверяли с оригинальным PDF.
- После выбора группы лента дней и количество занятий переключаются на её сохранённые данные.
- В **Настройках → О приложении** указано «Разработчик: Krabikk».
- Уведомления об изменениях пока отправляются только при выборе проверенной контрольной группы `2РПУ-25-1`. Для остальных групп они будут добавлены после отдельной проверки сравнения данных. **Разрешение на тестовые уведомления в меню разработчика остаётся отдельным.**

## Как протестировать на эмуляторе

1. Распакуй полный проект или наложи патч поверх 3.1.0-alpha.3 (с заменой файлов).
2. Запусти Gradle Sync и `:app:assembleDebug` в Android Studio. В этой среде Android SDK отсутствует — APK здесь не проверен.
3. Установи приложение, не очищая его данные. По умолчанию должна остаться группа `2РПУ-25-1` с её сохранённым расписанием.
4. Нажми **«Проверить обновления»** с интернетом. Когда загрузка PDF пройдёт, каталог остальных групп заполнится автоматически.
5. Нажми **«Группа: 2РПУ-25-1»** и найди `2ТМ-25-1`, `2ОНС-25-2` или `26-1 ЭМ`. Сверь предметы, время, кабинеты с PDF. Выбирай и переключай группы, затем перезапусти приложение — выбор должен сохраниться.
6. Выбери обратно `2РПУ-25-1`, убедись, что исходное расписание доступно, независимо от других групп.
7. Для глубокого контроля импортируй локальный PDF через **Настройки → Разработка → Каталог всех групп** и сравни извлечённые занятия с визуальной таблицей PDF.
8. В авиарежиме проверь, что сохранённый каталог и контрольная группа остаются доступны.

## Важные ограничения

Это **альфа-версия**, не релиз. На PDF за 18–19 ноября 2026 г. из 32 групп 25 не получили структурных предупреждений, 7 требуют ручной проверки. «Без структурных предупреждений» также не гарантирует точность по оригиналу. Не используй расписание сомнительных групп без сверки.

Загрузка каталога автоматически обновляется лишь после успешно распознанного контрольного расписания. Для уведомлений **произвольной** группы требуется следующий этап разработки. Выбор группы при первом запуске (onboarding) оставлен на отдельный этап, как было согласовано.
