# NNTC Schedule 3.1.0-alpha.3 — локальная проверка расписания всех групп

**Что это:** диагностическая сборка для эмулятора/Android Studio, не релиз.

## Новое

- **Настройки → Разработка → 3.1 • Проверка групп и PDF**.
- Выбор PDF с устройства через системный Android File Picker. Можно заранее перетащить PDF в эмулятор, если нет доступа к серверу колледжа.
- Сохранилась кнопка проверки PDF с официального сервера.
- Поиск группы по названию, горизонтальный список найденных групп, быстрый просмотр занятий и предупреждений.
- После успешной проверки сохраняется отдельный диагностический файл `group_catalog_preview.csv` во внутренней папке приложения. Его можно экспортировать через системный выбор места сохранения, даже если интернет выключен.
- Добавлены автоматические регрессионные проверки на втором PDF за 18–19 ноября 2026 года.

## Что важно

- Сканирование всех групп **не заменяет** действующий парсер группы `2РПУ-25-1`.
- Рабочая Room-база, WorkManager, уведомления и сохранённая выбранная группа не изменяются.
- Это пока диагностический CSV; назначить другую группу как основную на главном экране ещё нельзя.
- `STRUCTURAL_OK` означает отсутствие известных структурных проблем, **но не ручную проверку по оригиналу**.
- Сложные подгруппы с двумя преподавателями и многострочные кабинеты ещё требуют доработки и сверки.
- Два реальных PDF были проверены с помощью фикстур извлечённых символов (PyMuPDF). PDFBox-извлечение в Android может немного отличаться. Проверяй на эмуляторе.

## Как проверить на эмуляторе

1. Распакуй патч поверх `3.1.0-alpha.2` либо открой полный проект.
2. Выполни **Gradle Sync**, затем **Build → Make Project** или `:app:assembleDebug`.
3. Установи приложение на эмулятор.
4. Перетащи файл `Расписание занятий учебный корпус №2 (3).pdf` в окно эмулятора. Обычно он окажется в `Download`.
5. Открой **Настройки → Разработка → 3.1 • Проверка групп и PDF** и нажми **Выбрать PDF из файлов устройства**.
6. Проверь группы `2РПУ-25-1`, `2ОНС-25-2`, `1ИКСиС-26-1` и `1МРП-26-2`. Последние две имеют подгруппы, поэтому предупреждения ожидаемы.
7. Сохрани CSV и скопируй отчёт. Можно отправить его вместе со скриншотами неудачных строк.
