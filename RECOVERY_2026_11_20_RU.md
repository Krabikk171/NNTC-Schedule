# NNTC Schedule — восстановление beta.1 от 20.11.2026

## Обнаруженное

В присланном `Projects(1).zip` были смешаны старые и новые версии. `app/build.gradle.kts` задавал
`3.1.0-alpha.8.3` / versionCode 31, хотя сохранённый APK в `app/build/outputs/apk/debug/` был
собран как `3.1.0-beta.1` / 34. В `ExperimentalDesigns.kt` и `InterfaceStyle.kt` была
зарегистрирована лишь базовая тема «Маршрут», а файлы других экспериментальных дизайнов присутствовали.
Существовала лишняя копия исходников в `gradle/app/`. Отсутствовала настройка core library desugaring,
которая нужна дизайну «Орбита» на Android 7–8. Это обнаруженные несоответствия, а не подтверждённая
единственная причина пользовательского сбоя — его текст ошибки не был приложен.

## Как восстановлено

Использовано техническое ядро сохранённой проверенной `3.1.0-beta.1` (PDF/CSV, Room, WorkManager,
экран регистрации всех восьми экспериментальных дизайнов, темы, Gradle, tests). Поверх перенесены
самые свежие изменения интерфейса из пользовательского архива: «Маршруты 1/2» с прибытием/перерывами,
«Фокус 1», «Люмен», «Аквастекло», «Орбита», общие UI-оболочки, новые файлы
`ExperimentalChrome.kt` и `RouteArrivalUi.kt`. Локальные настройки, кеши, старые APK,
дубликат `gradle/app/` и личный ключ подписи НЕ вошли в архив.

## Установка

1. Не удаляй старый проект. Переименуй папку `C:\Android\Projects\NNTCSchedule` в
   `NNTCSchedule_backup_2026_11_20` (или просто сделай резервную копию).
2. Распакуй архив `NNTCSchedule_3.1.0-beta.1_RESCUE_source.zip` рядом. Папка внутри называется
   `NNTCSchedule`. Открой именно её в Android Studio (`File > Open`).
3. Локальный `local.properties` можно создать автоматически через Android Studio. Не копируй из
   старого архива `gradle/app/`, `app/build/`, `.gradle/`, `.idea/`, `release-key/`.
4. Gradle Sync → `:app:assembleDebug` → `:app:testDebugUnitTest`.
5. На эмуляторе сначала проверь запуск и меню «Разработка» (8 экспериментальных тем),
   потом выбранную группу, расписание и уведомления. Никакие данные приложения на эмуляторе не очищай.
6. Если Android Studio покажет ошибку, пришли первые строки `e:` / `FAILURE: Build failed` из Build Output.

## Альтернативный путь — минимальный патч

Для точного состояния присланного `Projects(1).zip` можно применить PATCH через
`python tools/apply_patch.py --patch <путь к ZIP> --project <путь к проекту>`.
Программа проверяет SHA-256, не затирает чужие изменения и создаёт бэкап заменённых файлов.
Не применяй патч на другие локальные ревизии без предварительной сверки.

## Безопасность

В присланном ZIP находились материалы подписи. Не выкладывай исходный 188-МБ архив в открытый
GitHub/Telegram. Храни ключ подписи отдельно и конфиденциально. Для отладки и передачи исходников
используй очищенный исходный проект. **Не удаляй оригинальный ZIP, пока не восстановишь сборку.**

Android-сборка восстановленной версии в среде ассистента не выполнялась: Android SDK отсутствует.
