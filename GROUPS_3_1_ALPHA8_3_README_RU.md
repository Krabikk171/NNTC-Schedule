# NNTC Schedule 3.1.0-alpha.8.3 — понятные статусы групп

Основа: 3.1.0-alpha.8.2 (ядро) + объединённый ранее UI «Маршрут».

## Почему появлялись красные предупреждения у многих групп

В Room сохранён результат диагностики последнего успешно обработанного PDF.
Одна обнаруженная проблема в занятиях помечает ВСЮ группу как `NEEDS_REVIEW`.
Старые статусы сохраняются после обновления APK, пока не скачан и не обработан свежий PDF.
Поэтому список мог показывать одинаковую страшную фразу для каждой группы, даже
когда более новая версия парсера уже умеет правильно читать этот документ.

## Изменения

1. В списке групп вместо повторяющейся красной фразы — число пар и замечаний;
   для проблемной группы остаётся компактный символ ⚠. Общая информация о
   количестве групп с замечаниями показывается один раз над списком.
2. Тот же принцип применён в мастере выбора студенческой группы.
3. Группа 2РПУ-25-1 в списках правильно использует контрольный проверенный
   механизм 3.0, поэтому не помечается предупреждениями экспериментального парсера.
4. В GroupScheduleStore добавлена консервативная защита: если меньше 20% групп
   успешно прошли структурную проверку, такой импорт отклоняется, а прежний
   каталог Room остаётся без изменений.
5. Старые данные НЕ удаляются, таблицы Room НЕ мигрируются, PDF-парсер,
   WorkManager и уведомления НЕ менялись.

## ВАЖНО: что делать после установки

Нажми «Проверить обновления» при доступном PDF. Только после УСПЕШНОГО
завершения новой синхронизации качества статусы будут пересчитаны.
В эталонном PDF за 19–21 ноября все 32 группы прошли структурную проверку.
Если после успешной проверки предупреждения всё ещё у ВСЕХ, приложи
`last_schedule.csv`/отчёт диагностики и лог GroupScheduleStore.
Не очищай данные приложения ради исправления статусов.

## Совместимость с дизайном и патчи

- `NNTCSchedule_3.1.0-alpha.8.3_core_patch.zip` — Kotlin-логика,
  тесты, версии и документация. НЕ включает Compose-файлы.
- `NNTCSchedule_3.1.0-alpha.8.3_ui_patch.zip` — только
  `GroupPickerDialog.kt` и `ProfileSetupScreen.kt`; сначала применить
  core, а затем UI, только если эти два файла не менялись дизайнером.
- `NNTCSchedule_3.1.0-alpha.8.3_full_patch.zip` — оба набора вместе.
- `NNTCSchedule_3.1.0-alpha.8.3_source.zip` — полные исходники на базе
  alpha.8.2; более свежая «Лента» не включена.

Безопаснее использовать `python tools/apply_patch.py --help` и проверить SHA
базовых файлов, чем просто копировать файл поверх изменений другого чата.
