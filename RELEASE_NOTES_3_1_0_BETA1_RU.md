# NNTC Schedule 3.1.0-beta.1

Тестовая версия приложения расписания для учебного корпуса №2.

**Что нового:**
- Поддержка выбора одной из 32 групп.
- Корректное отображение подгрупп с отдельными дисциплинами, кабинетами и преподавателями.
- Автоматическое обновление расписания и уведомления об изменениях выбранной группы.
- Защита сохранённого расписания при недоступности сети и ошибочном PDF.
- Обновлённый экран выбора группы и восемь экспериментальных вариантов интерфейса в меню разработчика.

Разработчик: **Krabikk171**.

**Статус:** бета. В случае ошибок при распознавании сверяйте занятия с исходным PDF. Приложение не является официальной системой колледжа.
