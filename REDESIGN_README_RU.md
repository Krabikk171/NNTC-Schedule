# NNTC Schedule 3.0.0-alpha.4 — редизайн

Новая версия основана на **рабочей 3.0.0-alpha.3**. Изменён интерфейс, не тронуты PDF/CSV-парсер,
`ScheduleRepository`, Room, Worker и механизм уведомлений.

## Что изменилось

- Новый главный экран: единая прокрутка, компактные карточки группы, статуса и дней.
- Карточки занятий: крупный номер, предмет, время, кабинет и преподаватель; длинный текст переносится.
- Две настроенные палитры (светлая и тёмная), в т. ч. оформление статус-бара.
- Раздел «Оформление» в настройках: **Как в системе**, **Светлая**, **Тёмная**.
- Визуальные иконки Material Icons вместо Unicode-символов.
- Сохранён тайный вход в Developer Screen: семь нажатий на номер версии.
- Добавлены `@Preview` для двух тем главного экрана.

## Установка

1. Распаковать архив в отдельную папку или перенести изменённые файлы поверх 3.0.0-alpha.3.
2. В Android Studio открыть корневую папку `NNTCSchedule`, где лежит `settings.gradle.kts`.
3. Дождаться Gradle Sync. Для иконок Gradle загрузит `androidx.compose.material:material-icons-extended`.
4. Build → Make Project (либо Build → Assemble Project / `:app:assembleDebug`).
5. Запустить на телефоне. Настройки → Оформление → выбрать нужный режим.
6. Для предварительного просмотра открыть `ScheduleHomeUi.kt` → Split/Design → выбрать `PreviewLightHome` / `PreviewDarkHome`.

## Изменённые файлы

- `app/build.gradle.kts` — версия и библиотека Material Icons.
- `MainActivity.kt` — подключение новой темы и `ScheduleHomeUi`.
- `ScheduleHomeUi.kt` — новый главный экран и карточки дней/пар.
- `SettingsScreen.kt` — новый вид настроек и выбор темы.
- `ui/theme/Theme.kt` — две цветовые палитры.
- `ui/theme/Type.kt` — типографика.
- `Changelog.kt` — запись об обновлении.
