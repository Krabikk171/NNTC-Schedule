# NNTC Schedule 3.0.0-alpha.6 — Лента дней

Версия сделана поверх исходников `3.0.0-alpha.5`.

## Что появилось

- Горизонтальная лента **Пн–Вс** на главном экране.
- Подсветка выбранной даты и тонкая обводка сегодняшней.
- Точка под датой означает, что в сохранённой базе есть занятия на этот день.
- Выбор даты: нажатие на чип; переход по неделям — стрелки в заголовке ленты; возврат к текущей дате — иконка календаря.
- Показывается только один выбранный день. Смена карточки анимирована.
- Когда на выбранную дату нет записей, приложение **не утверждает, что это выходной**, а сообщает об отсутствии данных в загруженном расписании.
- Если впереди есть другая сохранённая дата, внизу можно сразу открыть следующий день с занятиями.
- Лента и карточки получают цвета от действующего оформления Minimal / Aurora / Neon в светлом или тёмном режиме.

## Что оставили без изменений

`ScheduleRepository.kt`, `ScheduleTableParser.kt`, `ScheduleCsvCodec.kt`, `PdfDownloader.kt`, `ScheduleDatabase.kt`, `ScheduleDao.kt`, `ScheduleUpdateWorker.kt`, `NotificationHelper.kt`, настройки синхронизации. Формат БД и PDF-разбор не менялись.

Выбранная дата — временная настройка интерфейса, **не изменяет** сохранённое расписание. По умолчанию выбирается текущая дата, если она присутствует, иначе ближайшая будущая дата из локальной БД; если будущих нет — последняя сохранённая дата.

## Как установить

**Полный архив:** распаковать и открыть папку `NNTCSchedule` в Android Studio. Дождаться Gradle Sync. Собрать `Build > Make Project` или `:app:assembleDebug`.

**Патч:** распаковать в корень **проекта alpha.5** — туда, где лежит `app/` — с заменой совпадающих файлов. Новый `ScheduleDayStrip.kt` должен попасть в `app/src/main/java/ru/krabikk/nntcschedule/`. Не копируйте патч в папку `java` целиком.

Для Android Studio: `File > Sync Project with Gradle Files`, затем `Build > Make Project`.

## Самопроверка

1. Зайти в приложение, открыть ленту, выбрать день с точкой и убедиться, что показываются только пары выбранного дня.
2. Выбрать день без точки: появится сообщение об отсутствии записей, а старая база не будет стерта.
3. Проверить кнопки предыдущей/следующей недели и «Сегодня».
4. Открыть настройки, по очереди включить Minimal / Aurora / Neon и светлый / тёмный режимы.
5. Проверить «Проверить обновления» — работа загрузки PDF и уведомлений должна остаться прежней.

В `ScheduleDayStripTest.kt` есть тесты разбора дат, начального выбора дня, границ месяцев и лет.

## Статус

Локальные проверки **чистого Kotlin-класса дат** прошли. Полную Android-сборку здесь выполнить нельзя (нет Android SDK / доступной загрузки Gradle); APK не включён. Версия остаётся тестовой `alpha.6` до успешной сборки и проверки на устройстве.
