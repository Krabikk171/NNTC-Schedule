# Аудит дизайнерских изменений перед релизом 3.1.0

Исходная точка: `NNTCSchedule_3.1.0-beta.1_RESCUE_route_timeline_buildfix_source.zip`.
Последнее обновление дизайнера: `NNTC_Remaining_Concepts_10styles_update.zip` (20.11.2026).

## Проверенные изменения

1. Четыре файла обновления (включая новый экран) прошли проверку исходных/новых SHA-256 с предыдущей Rescue-бетой.
2. Экспериментальный каталог увеличился с 8 до 18: Космическая дуга, Хронолента, Компас дня, Импульс, Орбита Лайт, Сияющие грани, Коралловая ветка, Лунная дуга, Спектр, Северное сияние.
3. Новый экран `ScheduleRemainingConceptUi.kt` использует реальные `ParsedDay`/`ParsedLesson`, дату/неделю, подгруппы и существующий `onRefresh`.
4. Подписка на обновление времени выполняется только в Compose для текущего дня. Новый Worker и сетевой API не добавлены.
5. Файлы PDF-парсера, CSV, Room, WorkManager, уведомлений и прочие существующие реализации дизайнов не изменились.

## Исправлено в технической релизной подготовке

- Тесты, ожидавшие ровно восемь стилей, обновлены на 18.
- Релизный аудит обновлён на версию 3.1.0, versionCode 35 и 18 уникальных стилей.
- Сохранены исправления `dayKey`/`clockMillis` двух «Маршрутов» из Rescue-проекта.
- Версия синхронизирована между Gradle и `Changelog.CURRENT_VERSION`.

## Что нельзя подтвердить офлайн

Android/Jetpack Compose `assembleDebug` и `assembleRelease`, работа на реальном устройстве, визуальные переходы в каждой из 18 тем, полноценная миграция Room на устройстве, успешная установка подписанного APK. Перед публикацией выполнить инструкции `RELEASE_3_1_0_CHECKLIST_RU.md`.

## Граница проекта

В релиз 3.1.0 НЕ включены новые функции проверки/установки обновлений APK через GitHub, донаты и расписание преподавателей. Они остаются планами следующих версий. Экспериментальные дизайны не перенесены в обычные настройки до 4.0.0.
