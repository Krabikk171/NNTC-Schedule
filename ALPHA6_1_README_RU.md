# NNTC Schedule — 3.0.0-alpha.6.1

## Что добавлено

- **Настройки → Отображение расписания → Лента дней**: тумблер вкл/выкл.
- Включено (по умолчанию): выбор даты и недели, просмотр одного дня.
- Выключено: все дни последовательно, как в alpha.5.
- Переключение сохраняется через DataStore и применяется без перезапуска.
- Плавные переходы (Compose AnimatedContent, AnimatedVisibility, Crossfade, анимированные цвета и elevation).
- Все три стиля Minimal, Aurora, Neon работают в обоих режимах.

**Не изменены:** загрузка PDF, парсер PDF→CSV, Room, WorkManager и уведомления.

## Как установить

1. Открой проект `NNTCSchedule` из полного архива, либо перенеси файлы из патча по тем же путям поверх alpha.6.
2. В Android Studio: File → Sync Project with Gradle Files.
3. Build → Make Project (либо задача `:app:assembleDebug`), затем установи приложение.
4. Проверь оба состояния переключателя, разные недели и все три визуальных стиля.

## Проверки

Выполнена статическая проверка Kotlin-источников и целостности архивов. Android SDK в рабочей среде отсутствует, поэтому APK/assembleDebug здесь не проверены.
