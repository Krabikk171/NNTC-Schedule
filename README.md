# NNTC Schedule

**NNTC Schedule 3.1.0** — бесплатное Android-приложение для просмотра расписания ННТК по выбранной учебной группе.

**Разработчик:** Krabikk171.

## Возможности

- Загрузка и разбор PDF с расписанием занятий.
- Выбор одной из 32 учебных групп и отображение занятий по подгруппам.
- Локальное сохранение расписания для просмотра без интернета.
- Фоновая проверка изменений и уведомления об обновлении расписания.
- Светлая, тёмная и системная темы, пять основных стилей интерфейса.
- 18 **экспериментальных** оформлений в меню разработчика; их стабильность не гарантируется.

## Сборка из исходников

Нужны Android Studio, Android SDK и Gradle Wrapper из репозитория.

Минимальная версия Android: API 24.

```bash
./gradlew :app:assembleDebug :app:testDebugUnitTest
```

На Windows команда начинается с `gradlew.bat`.

## Безопасность

Не публикуйте ключ подписи `.jks`, его пароли, локальные настройки Android Studio или файлы `keystore.properties` и `local.properties`. Выпуски APK должны подписываться совместимым ключом для установки обновлений поверх предыдущих версий.

Автоматическое обновление самого APK и добровольная поддержка разработчика **планируются**, но отсутствуют в 3.1.0.
