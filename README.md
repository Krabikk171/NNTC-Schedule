# NNTC Schedule

**NNTC Schedule 3.1.0** — бесплатное приложение для Android, которое показывает расписание занятий ННТК по выбранной группе.

Разработчик: **Krabikk171**.

## Возможности

- Загрузка и разбор PDF с расписанием занятий.
- Выбор учебной группы и поддержка занятий по подгруппам.
- Сохранение расписания локально для просмотра без сети.
- Фоновая проверка изменений и уведомления об обновлённом расписании.
- Светлая, тёмная и системная тема, пять основных стилей.
- 18 **экспериментальных** вариантов оформления в меню разработчика (они не считаются полностью протестированными).

## Требования и сборка

- Android Studio, Android SDK и Gradle Wrapper из репозитория.
- Минимальная версия Android: API 24.

Откройте корневую папку проекта в Android Studio и выполните:

```bash
./gradlew :app:assembleDebug :app:testDebugUnitTest
```

В Windows используйте `gradlew.bat` вместо `./gradlew`.

**Примечание:** успешная локальная сборка подписанного APK разработчиком не равнозначна проверке всех экспериментальных экранов на каждом устройстве.

## Выпуски

Список изменений 3.1.0: [`RELEASE_NOTES_3_1_0_RU.md`](RELEASE_NOTES_3_1_0_RU.md).

Стабильные APK будут размещаться во вкладке **Releases** после публикации первого выпуска. Установочные APK и ключи подписи **не хранятся** в исходном коде.

## Безопасность подписи

Ключ подписи `.jks`, пароли, `keystore.properties`, `local.properties` и другие секреты должны храниться только локально и не загружаться в GitHub. Все будущие APK для обновления существующей установки должны иметь совместимую подпись.

Репозиторий пока не содержит отдельной лицензии на исходный код. Права на использование и распространение кода отдельно не предоставлены.
